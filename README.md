# OpenPDF

**OpenPDF** — вебзастосунок для перегляду та редагування PDF-документів. Проєкт перебуває на ранній стадії розробки (**Alpha**).

## Можливості

- Відкриття та перегляд PDF у браузері.
- Навігація сторінками та масштабування.
- Додавання текстових об’єктів.
- Аналіз текстових блоків і визначення сімейств шрифтів.
- Спроба редагувати наявний текст PDF через локальний сервер `ts-pdf-edit`.
- Фізичне видалення тексту з PDF через MuPDF.
- Скасування та повторення дій.

> **Важливо:** редагування наявного тексту залежить від структури конкретного PDF. Деякі шрифти, текст у вигляді контурів, скановані сторінки та нестандартні кодування можуть не підтримуватися. Застосунок має повідомляти про такі обмеження, а не гарантувати успішну заміну.

## Технології

- React

## Вимоги

- Node.js 20.19+ (рекомендовано актуальну LTS-версію)
- npm

## Запуск локально

```bash
git clone <URL-ВАШОГО-РЕПОЗИТОРІЮ>
cd openpdf
npm install
npm run dev
```

Відкрий адресу, яку покаже Vite (зазвичай `http://localhost:5173`).

Сервер `server.mjs` запускає Vite та локальний endpoint `/api/rewrite-pdf`. Не відкривай `index.html` безпосередньо з файлової системи — запускай застосунок через `npm run dev`.

## Перевірка та production-збірка

```bash
npm run lint
npm run build
```

Для локального перегляду production-збірки:

```bash
npm run preview
```

## Шрифти та сторонні компоненти

У `public/fonts` використовуються шрифти Liberation. Їхній текст ліцензії SIL Open Font License 1.1 міститься у файлі `public/fonts/LICENSE-liberation.txt`. Зберігай цей файл під час розповсюдження шрифтів.

Проєкт також використовує сторонні npm-пакети. Перед розповсюдженням зібраного застосунку ознайомся з ліцензіями залежностей, зокрема MuPDF та `ts-pdf-edit`.

## Ліцензія

Ліцензію самого проєкту ще не визначено. До її додавання всі права на вихідний код залишаються за автором. Ліцензії сторонніх залежностей і шрифтів діють окремо.

# Механізм безпосередньої заміни тексту

Ця версія передає редагування наявного тексту PDF локальному серверу на базі `ts-pdf-edit`. Новий текст, який додає користувач, як і раніше, малюється за допомогою `pdf-lib`.

## Локальний запуск

1. Встанови Node.js 20.19 або новішої версії.
2. Виконай `npm install`.
3. Запусти `npm run dev`.
4. Відкрий адресу, яку покаже термінал (зазвичай `http://localhost:5173`).

Dev-сервер обслуговує інтерфейс Vite та endpoint `/api/rewrite-pdf` на одному порту. Не відкривай `index.html` безпосередньо з диска.

## Відомі обмеження

- Сервер відмовляється замінювати текст, якщо точний вихідний фрагмент трапляється на вибраній сторінці більше одного разу. Це запобігає непередбачуваній заміні не того входження.
- Деякі PDF містять текст у вигляді контурів, шрифти Type 3, лише OCR-текст, пошкоджені потоки або непідтримувані кодування. У таких випадках механізм повідомляє про обмеження.
- Початковий шрифт повторно використовується, коли це можливо, але це не гарантується для кожного PDF і кожного нового символу.
- Ctrl+A, а потім Ctrl+C у застосунку копіює витягнутий текст документа з урахуванням незбережених замін. Це не те саме, що виділення тексту в PDF-переглядачі.
